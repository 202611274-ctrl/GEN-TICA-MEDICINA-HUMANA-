Tu web de genética, en GitHub Pages.

La aplicación es estática y funciona sin Firebase, sin claves API y sin suscripción a un servidor. Para alojarla con GitHub Free, usa un repositorio público. No necesitas comprar un dominio.

1. Pruébala en tu computadora

  1. Descarga y descomprime Genetica_URP_Web.zip.
  2. Abre la carpeta genetica-urp.
  3. Haz doble clic en index.html. Conserva las carpetas junto al archivo: contiene el banco y la interfaz.
  4. En celular y para instalarla como app, utiliza después la dirección HTTPS de GitHub Pages. Abrir archivos locales no habilita la instalación PWA y algunos navegadores restringen su almacenamiento.

2. Crea un repositorio

  1. Entra en GitHub y accede a tu cuenta, o crea una cuenta gratuita.
  2. Usa New repository. Ponle de nombre genetica-urp.
  3. Elige Public. Créalo con Create repository.
El código y las preguntas del repositorio serán públicos. Tu progreso se mantiene en tu navegador. No subas archivos de respaldo con apuntes personales, credenciales, audios o fotos de compañeros al repositorio público.

3. Sube los archivos descomprimidos

  1. Usa Add file → Upload files. En un repositorio vacío puede aparecer el enlace uploading an existing file.
  2. Arrastra el contenido de la carpeta genetica-urp: el archivo index.html y las carpetas assets, data y docs, además de sw.js, manifest.webmanifest y README.md.
  3. Comprueba que index.html quede en el primer nivel del repositorio. No subas únicamente el ZIP ni una carpeta que encierre toda la web en un nivel adicional.
  4. Confirma con Commit changes.

4. Activa GitHub Pages

  1. Abre Settings → Pages en el repositorio.
  2. En Build and deployment → Source, elige Deploy from a branch.
  3. Selecciona la rama main y la carpeta /(root). Pulsa Save.
  4. Espera a que GitHub termine la publicación. Vuelve a Pages y abre la dirección que muestra. El patrón habitual será https://TU-USUARIO.github.io/genetica-urp/.

Los pasos siguen la documentación de publicación de GitHub Pages. Si cambia la interfaz, esa página mantiene las instrucciones actuales.

5. Úsala en tu celular

Abre la dirección de GitHub Pages. En un navegador compatible, utiliza Instalar aplicación o Añadir a pantalla de inicio. En iPhone suele estar en el menú Compartir de Safari. La disponibilidad depende del navegador. Visita la web con conexión una primera vez para que se guarden sus recursos. Luego el contenido integrado puede usarse sin internet; Google Sheets y enlaces externos requieren conexión.

Añadir información y preguntas

Lo que quieres hacerDónde hacerlo
Crear una preguntaMi banco → Añadir pregunta. Introduce enunciado, alternativas, clave, explicación y fuente.
Importar variasMi banco → Importar y respaldar. Usa una plantilla JSON o CSV y revisa los cambios antes de confirmar.
Completar una pizarraMi banco → Revisión pendiente → Revisar → Completar mi revisión. Desmarca el estado pendiente solo después de confirmar el contenido.
Agregar contexto de clasesBiblioteca → Mis apuntes de esta semana. Pega texto revisado de tu clase, audio transcrito o PPT.
Actualizar el banco públicoExporta bank.js desde Mi banco y reemplaza data/bank.js en GitHub. El archivo no incluye tu historial, notas personales ni favoritos.
Cambiar de dispositivoExporta el respaldo completo y restáuralo en el otro navegador. No existe fusión automática: el respaldo restaurado reemplaza el avance local.

Conectar Google Sheets (opcional)

  1. Descarga la plantilla CSV desde Mi banco. Ábrela o impórtala en Google Sheets, conservando los nombres de columnas.
  2. Añade filas. Cada pregunta necesita un id único. En options, usa un arreglo JSON como ["Primera","Segunda"]. En correct, [0] significa primera opción y [1], segunda.
  3. En Sheets, publica la pestaña como CSV desde las opciones de publicación en la web. Copia el enlace público al CSV.
  4. Pégalo en Mi banco → Conectar una hoja de Google Sheets. Pulsa Revisar preguntas de la hoja.
  5. Revisa el número de preguntas nuevas y actualizaciones. Confirma la importación. No se aplican cambios automáticamente en segundo plano.

Si el enlace falla, descarga la pestaña como CSV e impórtala como archivo. Las nuevas preguntas solo estarán en tu navegador hasta exportar bank.js y actualizar GitHub.

Qué contiene esta primera versión

  • 205 registros: 143 de teoría previamente organizada, 51 de tareas de laboratorio y 11 registros de pizarras. Hay 178 habilitados, 22 en revisión y 5 complementarios.
  • Preguntas de una o varias respuestas, respuestas abiertas autoevaluadas, fuentes y notas de adaptación.
  • Práctica guiada, repaso espaciado por intervalos, errores y favoritos; simulacro con tiempo y nota sobre 20.
  • Ruta editable por cumplimiento de 21 días, progreso por semana y puntos de práctica.
  • Cruces genéticos, lector de CNV y mini casos de selección de pruebas.
  • Apuntes, importación/exportación, respaldo y uso sin conexión después de una visita completa por HTTPS.
Las respuestas abiertas no se corrigen con IA ni entran en la precisión objetiva. El repaso usa intervalos sencillos; no es FSRS. Las claves adaptadas son material de estudio y no equivalen a una revisión oficial de la facultad.

Si algo no se ve actualizado

Cierra todas las pestañas de la web y ábrela otra vez con conexión. Comprueba que GitHub haya terminado la publicación y que el archivo actualizado esté en el lugar correcto. Antes de borrar datos del sitio, exporta tu respaldo.
